# Cockfight_demo_game
This project is create a game with computer vision

## How to run this game?

1.Clone this git.

2.use `pip install opencv-python mediapipe numpy`

3.run `python cockcluck_demo.py`

## How to play?

1.Drag your finger to the hitbox to score(Use your index finger)

2.Press H for show/hide hitbox

3.Press Q to close or exit game

4.Press W/A/S/D for moving rooster (Debug only!)
